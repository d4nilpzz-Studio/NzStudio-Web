# Placeholders

- You can use these placeholders in almost all the builtin messages, just make sure to remove the `nzkoth_<KOTH>_` part, for example:

| PlaceholderAPI | Builtin |
| --- | --- |
| %nzkoth_<KOTH>_active% | %active% |

## List of placeholders

| Placeholder | Description |
| --- | --- |
| %nzkoth_<KOTH>_active% | true or false, is the koth running? |
| %nzkoth_<KOTH>_name% | the raw name of the koth |
| %nzkoth_<KOTH>_displayName% | the colored display name of the koth |
| %nzkoth_<KOTH>_world% | world of the koth |
| %nzkoth_<KOTH>_capper% | player currently capturing |
| %nzkoth_<KOTH>_time_left% | capture time left |

### Global

| Placeholder | Description |
| --- | --- |
| %nzkoth_next% | next scheduled koth |
| %nzkoth_next_time% | time until the next koth |
