# Commands

| Command | Permission | Description |
| --- | --- | --- |
| `/koth start <koth>` | `nzkoth.start` | Starts a koth |
| `/koth stop <koth>` | `nzkoth.stop` | Stops a koth |
| `/koth list` | `nzkoth.list` | Lists all koths |
| `/koth reload` | `nzkoth.reload` | Reloads the config |

See also the [placeholders](./03-placeholders.md).
